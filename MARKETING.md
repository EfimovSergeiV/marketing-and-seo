# Как поисковые системы находят и ранжируют сайты

Основная задача поисковика:

> Показать пользователю наиболее полезный и релевантный результат по его запросу.


---

## 1. Как работает поисковик

### Обход сайтов (Crawling)

Специальные роботы постоянно переходят по ссылкам и обнаруживают новые страницы.

### Индексация (Indexing)

Найденные страницы анализируются и добавляются в индекс — огромную базу данных поисковой системы.

### Построение поискового графа

Каждая страница становится узлом в графе интернета.

Поисковик учитывает:

* ссылки между страницами;
* структуру сайта;
* взаимосвязь тем;
* авторитетность ресурсов.

Упрощённо:

```text
Страница A ──► Страница B
      │
      └──────► Страница C
```

Чем больше качественных ссылок ведёт на страницу, тем выше её авторитет.

### Ранжирование

Когда пользователь вводит запрос, поисковик рассчитывает рейтинг страниц на основе множества факторов:

* соответствие запросу;
* авторитетность сайта;
* качество контента;
* поведенческие факторы;
* техническое состояние сайта.

После этого формируется поисковая выдача.

---

## 2. От чего зависит позиция сайта

Точная формула поисковиков неизвестна, однако основные группы факторов известны.

### Релевантность

Насколько содержание страницы соответствует запросу пользователя.

Например, по запросу:

> машина контактной стыковой сварки

страница должна содержать информацию именно об этом оборудовании.

### Авторитетность

Учитываются:

* ссылки с других сайтов;
* упоминания компании;
* возраст и репутация домена.

### Поведенческие факторы

Поисковик анализирует:

* кликают ли пользователи по результату;
* сколько времени проводят на сайте;
* возвращаются ли обратно к поиску.

### Технические факторы

* скорость загрузки;
* корректность HTML;
* адаптация под мобильные устройства;

---

## 3. Что такое SEO

SEO (Search Engine Optimization) — поисковая оптимизация сайта.

Цель SEO:

* помочь поисковику понять содержание сайта;
* повысить видимость в поисковой выдаче;
* привлечь больше целевых посетителей без платной рекламы.

Важно понимать:

> Современное SEO — это не попытка обмануть поисковик, а способ сделать сайт понятным как для поисковой системы, так и для пользователя.

---

## 4. Основные направления SEO

### Техническое SEO ( Тут у нас всё более-менее в порядке )

Обеспечивает возможность корректного обхода и индексации сайта.

Включает:

* отсутствие битых ссылок;
* корректные HTTP-коды;
* высокую скорость загрузки.

### Контентное SEO ( Тут есть над чем поработать )

Помогает поисковику понять тематику страницы.

Важны:

* заголовок страницы (Title);
* заголовок H1;
* описание (Description);
* полезный текст;
* характеристики товаров;
* изображения и их описания.

### Репутационное SEO ( Тут у нас всё более-менее в порядке )

Связано с авторитетностью ресурса:

* внешние ссылки;
* упоминания бренда;
* публикации на профильных площадках.

---

## 5. Пример SEO как выглядит сейчас

Плохой вариант:

```text
H1: Стыковая
```

Поисковику сложно понять тематику страницы.

Лучше:

```text
H1: Машины контактной стыковой сварки
```

Также полезно использовать:

```text
Title:
Машины контактной стыковой сварки | Производитель Техносвар КС

Description:
Производство и поставка машин контактной стыковой сварки. Доставка по России и за рубеж.
```

Такие формулировки точнее соответствуют запросам пользователей.

---

## 6. Влияние производительности сайта

Скорость работы сайта влияет на SEO, но не является главным фактором.

Поисковики учитывают:

* скорость загрузки;
* показатели Core Web Vitals;
* удобство использования на мобильных устройствах.

Инструмент Lighthouse позволяет выявлять проблемы производительности, однако высокий балл сам по себе не гарантирует высоких позиций.

Сайт с полезным контентом и хорошей репутацией часто будет ранжироваться выше более быстрого сайта с менее качественным содержанием.

# Вывод ( Что можно улучшить )

Для tehnosvar.ru я бы не стал начинать с технических мелочей вроде CDN, Lighthouse или микрооптимизаций. У сайта уже неплохая структура каталога и большая номенклатура оборудования. Основной потенциал роста сейчас лежит в контенте и семантике.

## 1. Переписать Title категорий

Сейчас встречаются заголовки вида:

```text
Контактная сварка - Сварочное оборудование, дуговая и контактная сварка купить на официальном сайте Техносвар КС в Пскове
```

Такой Title:

+ слишком длинный;
+ одинаковый для многих разделов;
+ содержит мало целевых запросов.

Я бы делал примерно так:

+ Машины контактной сварки | Производитель Техносвар КС
+ Машины контактной стыковой сварки | Производство и поставка
+ Сварочные трансформаторы ТВК и ТК | Техносвар КС

## 2. Убрать «в Пскове» почти из всех товарных страниц

У нас производство находится в Пскове, но оборудование продаётся по всей России и за рубеж.

Поэтому вместо:

```text
купить в Пскове
```

лучше:

```text
поставка по России и СНГ
```

или

```text
производитель сварочного оборудования
```

Город стоит упоминать:
+ на главной;
+ в контактах;


## 3. Добавить SEO-текст на категории

Я бы добавил блок 1500–2500 символов:

### Контактная сварка

+ что это такое;
+ где применяется;
+ какие типы машин выпускаются;
+ преимущества оборудования;
+ ссылки на категории.

Это даст поисковику больше семантики.


## 4. Создать посадочные страницы под запросы

Сейчас структура построена по типам оборудования.

Не хватает страниц под задачи пользователей:

Например:
+ Сварка арматуры
+ Сварка проволоки
+ Сварка труб
+ Контактная сварка рельсов

Люди часто ищут именно решение задачи, а не модель станка.


## 5. Максимально развивать раздел кейсов

На сайте есть сильная фраза:
```text
«Посмотрите, что мы уже сделали»
```

Из этого можно сделать огромный SEO-раздел.

Например:

```text
Сварка арматуры Ø40 мм для завода ЖБИ
```
```text
Модернизация машины МТ-1928
```
```text
Автоматизация сварки рельсов
```

Каждый кейс — отдельная страница.

Для промышленного B2B это работает очень хорошо.


## 6. Развивать раздел технической документации ( ОПЦИОНАЛЬНО )
У вас уже есть каталоги.

Я бы добавил:

+ паспорта;
+ руководства;
+ схемы подключения;
+ инструкции;
+ статьи.

Запросы вроде:
```text
ТВК-75 УХЛ4 характеристики
```
или
```text
МТ-1930 паспорт
```
могут приводить инженеров напрямую из поиска.


## 7. Усилить внутреннюю перелинковку

Например на странице трансформатора:
```text
Подходит для:
- МТ-1930
- МТ-2103
- МСО-201
```

На странице машины:
```text
Используемые трансформаторы:
- ТВК-75
- ТВК-110
```

## 8. Публиковать больше инженерного контента
На каждой категории.

Например:
### Машины контактной сварки

+ Как выбрать машину контактной сварки?
+ Какая мощность требуется?
+ Можно ли модернизировать старое оборудование?
+ Какой срок изготовления?

Это даёт дополнительную семантику и иногда позволяет попасть в расширенные сниппеты.

Публиковать полезные статьи:
+ Контактная сварка арматуры
+ Сварка высокопрочных сталей
+ Выбор сварочного трансформатора
+ Модернизация старых машин контактной сварки

Такой контент хорошо собирает поисковый трафик.
